#  Customer Behavior Analysis & Dashboard  

End-to-End Data Analysis + Interactive Dashboard Project  

---

##  Project Overview  
This project focuses on analyzing customer shopping behavior using a retail dataset to uncover patterns in purchasing, demographics, and customer engagement.  
The insights derived from Exploratory Data Analysis (EDA) are used to build an interactive dashboard using Streamlit for better business decision-making.

---

## Objectives  
- Analyze customer purchasing patterns  
- Identify top-performing product categories  
- Understand the impact of subscription status  
- Study customer behavior across different age groups  
- Build an interactive dashboard for visualization
